Projects

Project: Let Them Cook

Concept: Let Them Cook is a stategic, turn-based combat game. During combat, movements and attacks are done on a grid-based tile system, encouraging players to use each character's turn as efficient as possible. Both allies and enemies act according to the game's turn order system, where each character takes their turn based on their position in the queue.

Build Link: https://kenshinrr.itch.io/let-them-cook
GitHub Link: https://github.com/LollerCoder/Let-Them-Cook

Role: Head Game Developer and Programmer

Key Contributions: I developed the game's turn-based mechanics and designed the battle system. I also integrated the sound and environment effects/interactions in combat levels, as well as contributed in UI design and combat animations.

Project: Lost Souls

Concept: Lost Souls is a game where you find souls hiding inside the house. The said souls are scattered, hiding inside objects, and the only way to detect them is by using the candle which emits a green light when they are near a lost soul. Possessed items also do random actions, and also has a shine to help the players as well.

Build Link: https://kenshinrr.itch.io/lost-souls
GitHub Link: https://github.com/KenshinRR/Lost-Souls

Role: Developer/Programmer

Key Contributions: For this game, I developed the ghost tracker mechanic and also assisted in the level design

Project: Time to Time Out

Concept: Time to Time Out is a game about fighting different enemies from different timelines. In each levels, there are items that will spawn that both you and the enemies can get. Each item will have different effects, either good or bad. Each side also have three hostages that they must retrieve from the opposing side to win.

Build Link: https://kenshinrr.itch.io/time-to-time-out
GitHub Link: https://github.com/KenshinRR/Time-To-Time-Out

Role: Developer/Programmer

Key Contributions: For this game, I developed the offensive AI. Its features are movement, player tracking, player attack, and goal capture. I also worked on player controls.
